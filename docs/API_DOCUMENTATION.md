# API Documentation

## Base URL

http://localhost:5000/api

## Endpoints

### Health Check
- GET /health

### Auth
- POST /auth/register
- POST /auth/login
- POST /auth/send-otp

### Movies
- GET /movies
- GET /movies/:id
- POST /admin/movies (Admin)

### Users
- GET /users/profile
- PUT /users/profile
